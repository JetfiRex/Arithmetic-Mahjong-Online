# 云端部署与联机验收

本阶段采用 Docker + Render，沿用 FastAPI 和现有网页。服务运行 `python -m multiplayer.web`，使用单实例、单 worker。房间、分数和身份均在内存中，重启或部署清空。

## 首次部署

1. 提交本次代码，推送到这个私有仓库的部署分支。
2. Render 控制台连接有权读取此仓库的 GitHub 账号，新建 Blueprint，选择仓库中的 `render.yaml`。
3. 创建前检查付费计算方案、区域和单实例配置。当前方案 ID 为 `0.5c-512mb`，费用以控制台报价为准。
4. 确认 Docker 构建成功、一个 Uvicorn worker 正常启动，`/healthz` 返回 200。
5. 在 Render 环境变量中查看自动生成的 `INVITE_CODE`，私下把邀请码和网站 HTTPS 地址发给朋友。朋友先输入站点邀请码，再用房间名与房间密码加入牌桌。
6. 首次部署直接使用平台的 `PORT`、`RENDER_EXTERNAL_URL`。如使用自定义域名，先绑定并等待 HTTPS 就绪，再设置 `PUBLIC_ORIGIN=https://你的域名` 并重新部署；不能带路径或末尾 `/`。

配置依据 [Render Blueprint](https://render.com/docs/blueprint-spec)、[默认环境变量](https://render.com/docs/environment-variables)和[端口绑定](https://render.com/docs/web-services#port-binding)。健康检查单独接受平台内部 Host，游戏接口继续严格校验正式 Host/Origin，见 [Render 健康检查](https://render.com/docs/health-checks)。

提交触发的自动部署已关闭，发版安排在牌局结束后。不要增加 worker、扩到多个实例或打开自动扩容。平台维护、崩溃重启和手动部署仍会清空牌局；部署时新旧进程切换不承诺牌局连续。

## 通用 Docker 启动

```powershell
docker build -t arithmetic-mahjong-online .
# 本地创建不提交的 .env，填写正式 HTTPS 来源和随机邀请码。
docker run --rm --name arithmetic-mahjong-online --env-file .env -p 10000:10000 arithmetic-mahjong-online
```

`.env` 可从 `.env.example` 复制。程序本身不加载 `.env`，上面的 Docker 命令负责注入环境变量。通用 Docker 部署需要外部代理提供 HTTPS 与 WebSocket 转发；Render 已提供 HTTPS 入口。容器内部监听 HTTP `0.0.0.0:$PORT`，不同端口需同步修改映射。

镜像以普通用户运行，不包含 `.data` 模型、旧存档或 `.env`。站点邀请码不要放进 Git、公共 URL 或镜像；轮换邀请码需要重新部署，已有内存身份随重启失效。

## 真实异地验收

至少两位真人、两个独立网络，例如家庭宽带和外地宽带/手机蜂窝网络。四席都需在线；人数不足时可用独立浏览器窗口补席，但须记录实际人数和网络数。本机多窗口测试不能算异地通过。

| 步骤 | 通过标准 |
| --- | --- |
| 访问与邀请 | 两网络均可打开 HTTPS；缺少/错误邀请码不能创建身份，正确邀请码可进入大厅 |
| 入房 | 一人建带密码房间，另一网络朋友加入，错误房间密码被拒绝 |
| 四席开局 | 四席连接在线，房主安排座位后开局；每席只看自己的暗牌，观战按所选权限显示 |
| 操作同步 | 跨网络完成出牌、过牌和至少一次合法响应，对方看到相同牌河和当前回合 |
| 刷新交接 | 非房主刷新后回到同一席位，手牌不变，无错误关房 |
| 断线重连 | 非房主断网后全桌暂停，宽限内恢复原标签页后继续 |
| 超时托管 | 非房主超过宽限返回，本局仍托管，下一局可恢复真人 |
| 房主掉线 | 其他玩家在线时，房主单独断网超过容错，关房且未完成局不结算 |
| 结算 | 完成一局、安排下一局，累计分数保留，记录普通/血战的所测模式 |
| 服务重启 | 最后重启服务，旧身份失效，重新输入邀请码回到空大厅 |

失败时记录时间、操作、浏览器报错和服务实例 ID，不记录邀请码、Bearer 凭证或他人暗牌。`/healthz` 为 503 时看 tick 线程与服务日志；页面 403 核对正式来源；WS 不通检查 HTTPS/WSS 转发和 Origin。

全员断链会先保护暂停，全员超过 `SESSION_TTL_SECONDS` 未返回后关闭房间。其余情况下，在线身份不失效；离线观众、空闲身份和局间成员到期回收；正在对局的离线席位保留至本局结束，支持原凭证回来查看托管状态。
